# AI星座搭子 V0.2 Core Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 V0.1 全部可用路径的前提下，交付“同题双声道 → 主动确认 → 本地续聊 → 互动分享”的 V0.2 核心闭环及 P0 移动端体验修复。

**Architecture:** 新增两个无副作用的领域模块：`duel.ts` 只负责审核过的预置内容、对照人格和安全深链；`local-state.ts` 只负责浏览器本地状态的校验、覆盖与裁剪。现有 `ZodiacApp` 负责界面状态与浏览器副作用，服务端事件入口严格校验白名单后仅写安全维度计数。

**Tech Stack:** TypeScript 5.9、React 19、vinext/Next 16、Vitest 3、原生 localStorage/URL API、现有 Canvas 分享卡。

## Global Constraints

- 不增加模型调用、账户、云端历史、关系匹配、付费、社区、更多人格或重型运行时。
- 双声道只使用人工审核的通用情境与预置短回复；选择前不显示星座身份。
- URL、分享卡和事件均不得包含问卷答案、用户问题或聊天正文。
- 保留 V0.1 测试、直接选、结果、聊天、分享、Prompt/JSON 和 `/explore` 路径。
- 不提交、不推送、不部署；不修改 `docs/V0.2_PRODUCT_DECISION.md`。
