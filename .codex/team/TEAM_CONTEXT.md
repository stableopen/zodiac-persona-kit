# AI星座搭子团队上下文

更新日期：2026-08-01

## 长期角色

- CEO / 交付总协调：理解用户意图、冻结范围、分配任务、处理冲突、验收和最终汇报；不承担主要编码。
- 产品负责人：维护目标用户、价值主张、版本取舍、指标口径和所有者验收。后续优先恢复既有负责人；只有确实无法恢复时才更换运行实例，并先加载本目录与产品决策文档，明确“运行实例已更换、角色理解已恢复”。
- 技术负责人：本项目唯一主要代码写入者，负责方案、实现、测试、构建和运行证据。后续实现与修复优先继续既有负责人。

市场增长与 UX 角色在 V0.2 是临时独立调研顾问，不是长期负责人；仍有效的结论已进入产品决策与产品上下文。

## 协作规则

1. 产品负责人先冻结目标用户、唯一价值闭环、本期做与不做、可观察验收标准。
2. 技术负责人按冻结范围写入，保留已可用路径，并返回 Context delta。
3. CEO 只读复核真实实现和运行证据；问题定向退回原技术负责人。
4. 产品负责人做所有者复验；未通过的问题仍由原技术负责人修复。
5. 重大阶段把长期事实、决策、验收、风险和下一步沉淀到本目录，禁止保存完整对话、思维链、临时身份、原始日志或秘密。
6. 最终外部验收组如被启用，必须由三名全新、临时、只读的审计员分别检查产品价值与范围、技术正确性与测试、UX 与传播体验；不替代长期角色、不写代码、不直接改本目录。
