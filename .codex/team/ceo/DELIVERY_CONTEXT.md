# CEO 交付上下文

更新日期：2026-08-17

## 交付目标

把 AI星座搭子做成普通中文用户无需登录即可体验的开源 Web 产品。V0.2 唯一价值闭环是：

`测试或直选 → 同题双声道盲选 → 揭示差异 → 主动确认搭子 → 本地续聊或分享同一选择 → 朋友直接参与`

星座只作为熟悉、有趣的沟通隐喻；产品不做心理测量、命运预测或真人关系判断。

## 范围裁决

- 用户要求项目全过程使用 Git 管理和记录版本。每次可交付变更必须形成可回退提交，验收、部署和发布结论均引用对应提交 SHA；正式版本验收后进入 `main` 并打语义化标签。秘密与本地运行配置不得进入版本库。
- V0.2 只验证人格表达差异、主动确认、本地续聊和互动分享。
- 不做运势、星盘、关系匹配、账户、云端聊天历史、社区、排行榜、付费、长期记忆、双模型实时比较或重型 Agent 运行时。
- 开源项目可借鉴角色卡与多角色协作机制，但不复制 AGPL、限制性社区许可证或未审计实现。
- V0.3 是保守增量：只为已确认人格增加推进、安心、灵感三种任务模式和可编辑起手式；不重做 V0.1/V0.2，不生成 36 人格，不新增部署。
- 发布决策以产品所有者验收和 Node.js 22 GitHub Actions 为双门槛；本轮允许快进 `main` 并推送，但不打标签、不部署。

## 风险与边界

- 通过的是本地实现，不是公开部署或市场验证。
- 真实聊天仍依赖模型配置；系统分享兼容性尚未在真实手机环境全面验证。
- 本地真实聊天已用项目外进程配置验证；这些值未写入仓库或团队档案，服务重启后若未重新注入会按既有 503 路径降级。
- KV cohort 聚合为读后写，小流量可用，正式放量前需原子计数、事务存储或单写者聚合。
- IP/device 限额同样是读后写；共享公网 IP 可能使同一网络内用户共享访客额度，生产还依赖平台代理正确覆盖来源 IP。
- OG 绝对 origin 依赖页面请求经过当前 Worker 入口；真实平台路由仍需部署验证。
- 未满 7 日的 cohort 不得当作完整 D7 结果。
- V0.3 的模式价值、采用、复用、传播和商业性仍没有真实用户数据；匿名事件只代表可测，不代表假设成立。
- 既有 Sites/D1 与真实模型证据属于 V0.2 运行历史，不代表 V0.3 已部署；本轮公开交付只更新 GitHub `main` 源码。
- 当前远程为 `https://github.com/stableopen/zodiac-persona-kit.git`；标签和部署仍不在本轮授权范围。
